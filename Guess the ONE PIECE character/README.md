# 🏴‍☠️ 海贼王猜角色游戏 - Guess the ONE PIECE Character

一个基于《海贼王》角色数据的互动猜谜网页游戏，支持多语言和多种难度模式。

![游戏截图](https://via.placeholder.com/800x500.png?text=游戏界面预览)

## 🌟 功能特性

- **多语言支持**：中文、日本語、English
- **难度模式**：普通模式（10项属性）和困难模式（8项属性）
- **智能提示系统**：颜色标记（绿/黄/灰）和方向箭头
- **角色联想输入**：支持别名匹配和模糊搜索
- **数据可视化**：实时显示猜测历史记录
- **彩蛋与统计**：内置开发者信息和连胜记录
- **主题切换**：深色/浅色模式自由切换

## 🚀 快速开始

### 环境要求
- 现代浏览器（推荐 Chrome/Firefox/Edge 最新版）
- Web服务器（本地开发可用 `Live Server` 等工具）

### 使用步骤
1. 准备角色数据文件 `characters.json`（需符合项目数据结构）
2. 将 HTML 文件与 JSON 文件置于同一目录
